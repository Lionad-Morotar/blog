似乎没有开发者讨论 OpenAI 公布数学成果这件事情。

![莉央把手稿倒进深井，井里升起一个更大的机械自己](https://mgear-image.oss-cn-shanghai.aliyuncs.com/image/other/261011-openai-math-cover.jpg)

OpenAI 宣布在纳维-斯托克斯问题上取得突破，同时一口气公布了三百多个长期未解数学问题的进展。

纳维-斯托克斯是千禧年大奖难题之一，悬赏一百万美元，人类最聪明的头脑啃了九十年。但故事很快转向另一面，OpenAI 被指控从一位数学家的聊天记录里拿到了方法。

这位数学家叫巴克马斯特，在纽约大学工作。他和合作者在研究里全程用着几个大语言模型，包括 OpenAI 的 Codex，草稿和对话都存在云端。他秘密研究的纳维-斯托克斯问题持续一年的那条路径，OpenAI 用不到一周走完了同一条。
他说自己曾主动联系 OpenAI 的数学家，对方承认公司正在做同一个问题。

按巴克马斯特的说法，OpenAI 随后提了一个条件：他和同事可以先发表成果、去申报那一百万美元奖金，代价是把同事从发现者署名里抹掉，理由是那位同事在 Anthropic 工作。他拒绝，然后公开了整件事，
还说自己收到的回复高度暗示对方在试图收买他。OpenAI 在 X 上称他的说法虚假且具有煽动性，OpenAI 的数学家也否认提过抹署名的事情。

但关于是否使用了巴克马斯特的数据进行训练，或数据对攻克难题产生了帮助，OpenAI 闪烁其词。

数学家和 OpenAI 的故事非常简单，就到此为止，但我认为开发者对这件事情不那么关注是有原因的。

一个人攒了一年的东西，别人一周就复制了，这个处境开发者太熟了。维护了几个月、几年的系统，AI 几个小时就能生成一个一样的，这件事非常让我恐慌。但不那么致命的是，尽管 AI 写代码很强，在系统设计层面还差些火候。所以开发者的心情理应是混合的，
有惊喜，有焦虑，也可能是和我一样兴奋，只是还没到数学家那种恐惧变成敌对的底部。这件事因人而异。但坦言如果把我自己放到那个位置，会非常难接受。

另一点有意思的是，开发者目前似乎不在意“你正在训练击败你的模型”这件事情。

半年前有反蒸馏相关的事情，现在已经不流行了。前阵子Z 家上传云端的事件，据我观察大家的宽容度也挺高。更特喵离谱的是，我身边不少同事朋友中转站照用不误。把 API key 和对话交给一个不知底细的网站。所以目前的数据安全到底有多“安全”，
很难想象。

巴克马斯特担心 OpenAI 用自己没有发表的证明去训练一个击败自己的模型。其实开发者的处境其实差不了多少，只是模型能力暂时还没强到碾压开发者的这天。

不过应该也快了吧。
