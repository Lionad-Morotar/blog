似乎没有开发者讨论 OpenAI 公布数学成果这件事情。

![莉央把手稿倒进深井，井里升起一个更大的机械自己](https://mgear-image.oss-cn-shanghai.aliyuncs.com/image/other/261011-openai-math-cover.jpg)

OpenAI 宣布在纳维-斯托克斯问题上取得突破，同时一口气公布了三百多个长期未解数学问题的进展。

纳维-斯托克斯是千禧年大奖难题之一，悬赏一百万美元，人类最聪明的头脑啃了九十年。但这件事还有另一面：OpenAI 被指控从一位数学家的聊天记录里拿到了方法。

这位数学家叫巴克马斯特，在纽约大学。他和合作者做研究时全程用着几个大语言模型，包括 OpenAI 的 Codex，草稿和对话都存在云端。他秘密研究了一年的那条纳维-斯托克斯路径，OpenAI 用不到一周走完。
他说自己曾主动联系 OpenAI 的数学家，对方承认公司正在做同一个问题。

按巴克马斯特的说法，OpenAI 随后提了一个条件：他和同事可以先发表成果、去申报那一百万美元奖金，代价是把同事从发现者署名里抹掉，理由是那位同事在 Anthropic 工作。他拒绝，然后公开了整件事。
他说对方后来的那几番回复，高度暗示是在试图收买他。OpenAI 在 X 上称他的说法虚假且具有煽动性，自家的数学家也否认提过抹署名。

但关于是否用巴克马斯特的数据训练过，或数据对攻克难题有没有帮助，OpenAI 一直闪烁其词。

数学家和 OpenAI 的故事到这里就结束了，很简单。但开发者对这件事不那么关注，是有原因的。

攒了一年的东西，AI 一周就复制了，这个处境开发者太熟了。维护几个月、几年的系统，AI 几个小时就能生成一个一样的。
AI 写代码很强，系统设计层面还差些火候，所以开发者没那么杞人忧天，还没被推到那种恐惧变成敌对的地步。
对这件事的感受因人而异。但坦言换我在那个位置，会非常难接受。

另一点有意思的是，开发者目前似乎不在意“你正在训练击败你的模型”这件事情。

半年前有反蒸馏相关的事情，现在已经不流行。前阵子 Z 家上传云端的事件，据我观察，大家的宽容度也非常高。但特喵离谱的是，我身边不少同事朋友，就算中转站也还是照用不误。
把 API key 和对话交给一个不知底细的网站，目前所谓“数据安全”到底有多安全，不难想象。

巴克马斯特担心 OpenAI 用自己没有发表的证明去训练一个击败自己的模型。开发者的处境差不了多少，虽说模型能力目前还没碾压开发者的，不过应该也快了吧。
